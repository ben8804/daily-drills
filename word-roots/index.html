room 房间族

看见 room，多半是一个房间。

room，房间、屋子。

长成了 进度记在这台设备上。

拼这一族

这一族的词

  1. classroom 教室 class 班级，room 房间 U1
  2. bedroom 卧室 bed 床，room 房间 U4
  3. bathroom 卫生间 bath 洗澡，room 房间 U4
  4. living room 客厅 living 起居，room 房间 U4 两个词，中间有空格

school / book 书包族

school 是学校，book 是书，拼在一起就变成书包里的东西。

book，书。

长成了 进度记在这台设备上。

拼这一族

这一族的词

  2. storybook 故事书 story 故事，book 书 U2
  3. notebook 笔记本 note 笔记，book 书 U2
  4. English book 英语书 English 英语，book 书 U2
  5. maths book 数学书 maths 数学，book 书 U2
  6. Chinese book 语文书 Chinese 语文，book 书 U2

-er 职业族

词尾加上 er，常常变成「做这件事的人」。

-er，做这件事的人。

长成了 进度记在这台设备上。

拼这一族

这一族的词

  1. teacher 教师 teach 教，er 的人 U6 teach 教；teacher 教书的人。U1 还有 teacher’s desk 讲台。
  2. driver 司机 drive 开车，er 的人 U6
  3. farmer 农民 farm 农场，er 的人 U6
  4. player 运动员 play 玩、打球，er 的人 U6 课本里是 football player 足球运动员
回到词族

friend → friendly

friend 是朋友，加上 -ly 变成「友好的」。

-ly，……的（形容词）。

长成了 进度记在这台设备上。

拼这一族

这一族的词

  1. friend 朋友 friend 朋友 U3
  2. friendly 友好的 friend 朋友，ly ……的 U3
